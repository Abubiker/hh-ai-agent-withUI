# HH Agent — приложение для macOS

Оконная версия агента: тот же поиск и отклики, но с интерфейсом, выбором модели
и уведомлениями на рабочем столе. Консольная версия (`main.py`) продолжает
работать — ветка ничего в ней не ломает.

## Что умеет

- **Кнопка «Запустить»** вместо терминала, выбор длительности сеанса, остановка
  в любой момент (кнопка, иконка в строке меню или `/stop` в Telegram).
- **Живой журнал** — видно, что агент делает прямо сейчас.
- **Статистика сеанса**: просмотрено, отсеяно, откликов, писем и так далее.
- **Настройки в окне**: резюме, запросы, фильтры, регионы, паузы.
- **Выбор модели**: локальная Ollama (со списком установленных и загрузкой новых
  прямо из окна, включая GGUF с HuggingFace), любой OpenAI-совместимый сервер
  (LM Studio, llama.cpp server, Groq) или Anthropic по ключу.
- **Капча в окне**: агент делает скриншот, окно показывает его и принимает ответ.
- **Уведомления на рабочем столе** о найденных вакансиях и ответах работодателей.

Ключи и токены хранятся в Keychain, а не в файлах настроек.

## Установка из DMG

1. Скачайте `HHAgent.dmg` из релизов и перетащите приложение в «Программы».
2. **Первый запуск**: правый клик по приложению → «Открыть» → «Открыть».

   Так нужно, потому что сборка подписана ad-hoc, а не нотаризована Apple
   (нотаризация требует платного аккаунта разработчика). Если macOS всё равно
   отказывается, снимите карантин:

   ```bash
   xattr -dr com.apple.quarantine "/Applications/HH Agent.app"
   ```

3. При первом открытии приложение покажет, чего не хватает: браузера Playwright,
   входа в аккаунт HH, названия резюме. Браузер ставится кнопкой.

## Запуск из исходников

```bash
python3.11 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python ui_app.py
```

Учтите: **уведомления при таком запуске не появятся**. macOS показывает их
только от подписанного приложения — это ограничение системы, а не ошибка.
Проверить можно так:

```bash
.venv/bin/python ui_app.py --selftest
```

## Сборка

```bash
./build_app.sh
```

Скрипт соберёт `dist/HH Agent.app` и `dist/HHAgent.dmg`. Ad-hoc подпись
выполняется автоматически — без неё не работают уведомления.

Проверить собранное приложение, не открывая окно:

```bash
"dist/HH Agent.app/Contents/MacOS/HHAgent" --selftest
```

Ожидаемый вывод: определился `bundle_id`, уведомления доступны, готовность
по всем пунктам.

## Где что лежит

Настройки и данные — в `~/Library/Application Support/HHAgent/`:

| Файл | Что это |
|---|---|
| `settings.json` | все настройки (без секретов) |
| `state.json` | сессия HH — чтобы не логиниться заново |
| `agent.db` | какие вакансии уже обработаны |

Секреты (токен бота, API-ключи) — в Keychain, служба `HHAgent`.

Браузер Playwright намеренно не входит в приложение: с PyInstaller у него
ломаются пути, а размер вырос бы втрое. Ставится один раз кнопкой при первом
запуске.

## Известные ограничения

- Сборка не нотаризована — при первом открытии нужен правый клик → «Открыть».
- Сборка только под macOS. Код кроссплатформенный (PyWebView, Playwright и
  уведомления работают и на Windows/Linux), но сборка и проверка под другие
  системы не делались.
- HH.ru запрещает автоматизацию откликов правилами сервиса. Аккаунт могут
  заблокировать — риск на вас.
