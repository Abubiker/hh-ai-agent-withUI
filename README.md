# AbuHH

Десктопное приложение (macOS, Apple Silicon). Ищет вакансии на hh.ru и
однодоменных площадках HeadHunter (hh.kz, hh.uz, rabota.by, hh1.az),
отсеивает нерелевантное фильтром и ИИ, пишет персональное сопроводительное
письмо под каждую вакансию по вашему профилю и отправляет отклик. Всё через
окно — терминал не нужен.

## Требования

- **Camoufox** — антидетект-браузер, на котором работает вся автоматизация
  (Playwright API поверх него). Не входит в сборку (~700 МБ), ставится одной
  кнопкой при первом запуске.
- **Модель** — одно из двух:
  - локальная **Ollama** (бесплатно, свой компьютер, нужно ~16 ГБ памяти);
  - облачная модель по API-ключу: любой OpenAI-совместимый сервис
    (OpenRouter, Mistral, Groq, Google Gemini, NVIDIA Build, LM Studio,
    произвольный адрес) или Anthropic.

Мастер первого запуска проверяет оба пункта по порядку и для модели
предлагает выбор — Ollama или ключ — прежде чем перейти к резюме и поиску.

## Возможности

- Поиск по нескольким запросам и регионам одновременно, с пагинацией и
  дедупом уже обработанных вакансий.
- ИИ-фильтр вакансий поверх хардкодед стоп-слов — отсекает нерелевантное,
  даже если прошло по ключевым словам.
- Персональное сопроводительное письмо под каждую вакансию, без выдуманных
  фактов, со вторым проходом-проверкой перед отправкой.
- Автоответы на текстовые вопросы теста работодателя по данным профиля и
  анкеты; если данных не хватает — уведомление на ручной отклик.
- Капча — прямо в окне приложения.
- Уведомления на рабочий стол и (опционально) в Telegram.
- Статистика по сеансам: воронка, история откликов, причины отказа.
- Чат с моделью внутри приложения — вопросы по резюме, разовый отклик по
  ссылке на вакансию.

## Установка

`AbuHH.dmg` из [Releases](../../releases) → перетащить в «Программы».
Сборка ad-hoc, без платной подписи Apple — при первом запуске нужно один раз
разрешить через Системные настройки → Конфиденциальность и безопасность.
Только Apple Silicon. Подробности и Linux — [УСТАНОВКА.md](УСТАНОВКА.md),
[LINUX.md](LINUX.md).

## Данные приложения

`~/Library/Application Support/AbuHH/`:

| Файл | Содержимое |
|---|---|
| `settings.json` | настройки, без секретов |
| `secrets.json` | токен бота и API-ключи, права 0600 |
| `state.json` | сессия hh.ru |
| `agent.db` | история откликов, статистика, кэш вердиктов ИИ |
| `logs/` | файловые логи по сеансам |

Сброс к заводским настройкам — удалить эту папку.

## Ограничения

- Сборка не нотаризована Apple.
- hh.ru запрещает автоматизацию откликов правилами сервиса — риск блокировки
  аккаунта на пользователе.
- Автоответ на тест работодателя — только текстовые вопросы, радио/чекбокс
  уходят на ручной отклик.

## Разработка

```bash
python3.11 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python ui_app.py
```

Сборка `.app`/`.dmg`:

```bash
./build_app.sh
```

Тесты:

```bash
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/pytest tests/
```

Headless-режим (без окна, для сервера/ssh) — тот же `settings.json` через
консольный мастер:

```bash
python wizard.py
python main.py
```
