Резюме на hh.ru

Название должно совпадать с заголовком резюме посимвольно — иначе агент не найдёт его в момент отклика.

Модель пишет письма строго по этому тексту. Чем конкретнее — тем меньше выдумок.

Поисковые запросы

По одному в строке. Короткие точнее: «Тестировщик» поймает и «Тестировщик ПО», и «Старший тестировщик».

Без этого HH ищет слова и в описании — тогда в выдачу лезут посторонние вакансии.

Объём и темп

Круг — полный проход по всем запросам. Больше страниц и меньше пауза — больше нагрузка на HH и выше риск блокировки.

Опыт работы

Какие градации опыта запрашивать у HH.

Регионы

По строке на регион, в формате «Название | параметры». Например: Москва | &area=1

Провайдер

Нажмите «Проверить», чтобы убедиться, что модель отвечает.

Ollama

Модель крутится в отдельной программе Ollama — приложение ею только управляет. Ollama ставится один раз, модели скачиваются сюда же и остаются на компьютере.

Скачать модель

Можно обычное имя (gemma4:e4b-it-qat) или ссылку на GGUF с HuggingFace (hf.co/автор/репозиторий:квант).

OpenAI-совместимый сервер

Подходит для LM Studio, llama.cpp server, LocalAI, Groq.

Anthropic

Ключ хранится в Keychain, а не в файле настроек.

Куда сообщать

Работают только в собранном приложении: macOS не показывает уведомления от неподписанных программ.

О чём сообщать

Касается только уведомлений. В журнале окна видно всё в любом случае.

Хранение токенов

По умолчанию токены лежат в файле, доступном только вам (права 0600) — система ничего не спрашивает. Связка надёжнее, но после каждого обновления приложения macOS будет просить пароль от Связки, потому что подпись программы меняется.
